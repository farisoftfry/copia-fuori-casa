copia-fuori-casa

Applicazione personale, per uso privato di un solo utente. Copia ogni giorno i backup già cifrati di un server domestico su Google Drive, in un account dedicato, per poterli recuperare se il server si rompe.

Usa soltanto il permesso drive.file: vede e gestisce solo i file che crea lei, non il resto del Drive.
